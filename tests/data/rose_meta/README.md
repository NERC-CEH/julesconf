# JULES rose metadata extract

`vn7.9.json` is a normalised extract of the rose metadata that ships with the
JULES model, covering the release julesconf's schemas are pinned to.

## Provenance

- Upstream: [MetOffice/jules](https://github.com/MetOffice/jules),
  `rose-meta/jules-standalone/vn7.9/` plus the ten `rose-meta/jules-shared/*/vn7.9/`
  packages it imports. The exact commit is recorded in the extract's
  `provenance` header, along with the full list of source files.
- Generated by `scripts/rose_meta_extract.py`, which reads a local checkout —
  it never touches the network.

## Regenerating

```
git clone --filter=blob:none --sparse https://github.com/MetOffice/jules reference/jules
git -C reference/jules sparse-checkout set rose-meta rose-stem
python scripts/rose_meta_extract.py extract
```

`reference/` is gitignored; the checkout is not part of this repository. The
extract is committed so that the audit and the test suite need neither the
checkout nor the network.

To see how julesconf's schemas compare against it:

```
python scripts/rose_meta_extract.py audit
```
